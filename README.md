# EGR
Evidence-Gated Regularization (EGR), method proposed in "Sensing Which Modality Matters: Evidence-Gated Regularization for Robust VLA Policies".

**Project page:** https://yy-gx.github.io/EGR/

## Repository layout

| Path | Contents |
|---|---|
| `website/` | Source of the project page (Astro + Tailwind). `npm install && npm run dev` to preview. |
| `.github/workflows/deploy-site.yml` | Builds `website/` on every push to `main` and publishes to the `gh-pages` branch. |
