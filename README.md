# EGR

**Sensing Which Modality Matters: Evidence-Gated Regularization for Robust VLA Policies**

Yue Yang, Diego Romeres, Chiori Hori, Gedas Bertasius, Daniel Szafir, Siddarth Jain
· UNC Chapel Hill and Mitsubishi Electric Research Laboratories (MERL)

📄 **Project page:** <https://yy-gx.github.io/EGR/>

Evidence-Gated Regularization (EGR) is a modality-agnostic training objective
that teaches a VLA policy which sensors to rely on at each frame, ignoring the
ones that carry no task-relevant signal and falling back on the one that does.
It adds no inference-time cost.
